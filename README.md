# 🚀 Agency Landing Page

A modern, responsive agency landing page built using **HTML and CSS**.
The project focuses on clean UI design, responsive layouts, interactive hover effects, animations, feature sections, customer reviews, integrations, and a contact form.

## 📌 About the Project

This project is a frontend website designed for a digital agency/business.

It includes:

* Responsive navigation bar
* Hero section
* Call-to-action buttons
* Email/demo form
* Agency/service section
* Process/workflow cards
* Feature section with interactive images
* Customer review section
* Integration section
* Contact form
* Hover effects
* CSS animations
* Responsive design for mobile, tablet, and desktop

The website uses CSS animations such as scale and fade effects to create a more interactive user experience.

## 📱 Responsive Design

The website uses CSS media queries to make the layout mobile-friendly.

For example:

```css
@media (max-width: 768px) {
    .container {
        flex-direction: column;
    }
}
```

The navigation also changes to a mobile menu on smaller screens.

## 🌍 Deploy on GitHub Pages

1. Push the project to GitHub.
2. Open your repository.
3. Go to **Settings**.
4. Select **Pages**.
5. Under **Build and deployment**, select:

   * Source: `Deploy from a branch`
   * Branch: `main`
   * Folder: `/ (root)`
6. Click **Save**.
7. GitHub will provide your live website URL.
